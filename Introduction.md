# Introduction to JavaScript  

JavaScript is used to create **dynamic functionality** on web pages.  
By using JavaScript, we can perform **client-side validations**.  

---

## History of JavaScript  

- Developed by **Brendan Eich** in the year **1995**.  
- Initially developed by **Netscape Navigator**.  
- At first, it was called **LiveScript**.  
- Later, the name was changed to **JavaScript** to gain popularity.  

---

## Standardization  

- JavaScript was standardized by the **European Computer Manufacturers Association (ECMA)**.  
- ECMA is responsible for releasing new versions of the language.  
- The standardized version is known as **ECMAScript**.  
- **ECMAScript 2015 (ES6)** is one of the major updates, also referred to as **Modern JavaScript**.  

---

## JIT (Just-In-Time Compiler)  

- JIT stands for **Just-In-Time Compiler**.  
- It is the process of compiling computer code **during execution of a program (at runtime)** rather than before execution.  
- The JIT compiler improves performance by compiling bytecode into native machine code at runtime.
